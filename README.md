# RepositorioIvan 🚀

Este es un repositorio educativo creado para practicar comandos de Git y flujos de trabajo con diferentes tipos de archivos.

## 📁 Estructura del Proyecto
* `notas.txt`: Texto plano.
* `app.py`: Script de Python.
* `script.js`: Código JavaScript.
* `index.html`: Estructura web.
* `README.md`: Guía del proyecto.
