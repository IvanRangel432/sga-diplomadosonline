# Sistema de Gestion Academica 

# Descripcion 
 
 En este proyecto esta basado en solucionar la perdida de datos en hojas de calculo En excel, dentro de una institucion Llamada "Diplomados Online". Ya que en esta problematica, la junta directiva ha decidido crear un Motor Core (Backend) que se llama "Sistema de Gestion Academica" y por medio de esta se ejecutara en un sistema de comando de 7 opciones.

 # Estructura del Proyecto 
**`docs/`**: Implementacion de los Entregables de la Fase 1 (Analisis del Problema) y Fase 2 (Diagramas UML)
**`python/`**: Implementacion de codigo fuente del primer prototipo en Python de la problematica.
**`java/`**:Codigo fuente implementada en Java de la problematica.
**`cpp/`**: Codigo fuente implemetada en C++ de la problematica.
  
# Reglas de Negocio 
 **Curso**:El criterio de evalauacion se basa en que el promedio de las tres notas tiene que ser mayor o igual a 10/20
 **Diplomados**:El promedio de las tres notas tiene que ser mayor o igual a 14/20.
 **Bootcamp**:En este caso no se aprueba por promedio, pero exige que ninguna nota debe estar por debajo de 14/20, si la nota esta por debajo de 14/20, esta reprobado.
